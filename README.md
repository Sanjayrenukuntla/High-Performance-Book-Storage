# High-Performance Book Storage System

## Overview
A full-stack web application designed to optimize book storage and retrieval. This system addresses the "cold start" problem in recommendation engines by using user interest mining and normalized database structures.

## Key Features
* **Normalized Storage:** Reduced data redundancy using 3NF database design.
* **Recommendation Engine:** Implements collaborative filtering to suggest books based on user history.
* **Admin Dashboard:** features for inventory management and sales visualization.
* **Tech Stack:** Java (J2EE), JSP, MySQL/MongoDB, HTML/CSS (Bootstrap).
